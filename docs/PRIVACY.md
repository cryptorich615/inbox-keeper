# Privacy boundary

Inbox Keeper currently operates entirely on fictional sample data. It does not request, transmit, or store email credentials, OAuth tokens, message bodies, attachments, or real inbox metadata.

Local browser storage contains only demo messages, theme preference, protected sample addresses/domains, Trash state, and the demo activity log. **Reset sample data** removes the saved demo state and restores defaults.

Any live-provider phase must ship with a separate privacy review and an explicit data-retention policy before accounts can connect.
